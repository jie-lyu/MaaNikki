# MaaNikki Mac 测试版使用说明

这是给少数测试者的 Mac 测试版，不是正式版。它的版本号与同期的 Windows 版相同，用窗口标题区分：标题里写着「Mac 测试版」和构建所用的提交号（例如「MaaNikki Mac 测试版（1a2b3c4）」），反馈问题时请一并报告这个提交号。

## 从哪里下载

打开 https://github.com/jie-lyu/MaaNikki/releases ，找标题里写着「Mac 测试版」的预发布版本，一般用最新的那一个（维护者另有指定时以指定的为准）。每个版本的标题都写着构建所用的提交号，装好打开后，应用窗口标题里的提交号应与它相同。在该版本页面下方的 Assets 里直接下载 `MaaNikki-v<版本>-macos-arm64-test-<提交>.dmg`，不需要登录 GitHub，也不用解压；同名的 `-SHA256SUMS.txt` 校验文件就在它旁边。

这些版本发布在维护者的 fork 上，是给少数测试者的测试版，不是项目的正式发布。

## 运行条件

- Apple 芯片（M 系列）的 Mac，macOS 14 或更高版本。
- App Store 版《无限暖暖》，画面设置为「全屏窗口模式」，游戏放在外接的 16:9 显示器上，运行任务期间保持在最前面。MacBook 自带屏幕、窗口模式、后台运行都不支持。

## 任务分三类

任务在 Mac 上分成三类，清单随测试版更新：

- **已验证**：在 Mac 上实际跑通过，没有特别标记。其中有说明的任务名旁边有一个 ⓘ 图标，鼠标停在上面可以看到仍未覆盖的部分，例如每周免费礼包每次滚动一行的距离未测、月卡在已解锁乐园构想的账号上的领取流程未验证。
- **实验性**：Mac 上可以选，但还没有在 Mac 上实际跑过。任务名旁边有黄色的「Mac 未验证（试用）」标记，任务列表里直接写出它会产生的后果（例如会用掉活跃能量、可能把能力永久保存进能力方案），开始运行时任务日志里也会先写一行「本任务尚未在 Mac 上验证（试用）」。第一次运行请人在旁边看着，出现异常立刻停止。
- **不可用**：在 Mac 上不能用或已知有问题（例如启动和关闭游戏要手动完成），选择任务时是灰色的、不能添加；以前保存的任务里如果有，运行时会跳过并写明原因。

出现异常时请先在客户端里停止任务，再导出日志反馈（见下文）。

## 安装

1. 按上面「从哪里下载」取得 dmg 和 SHA256SUMS 文件。想确认文件完整，可以在「终端」里运行 `shasum -a 256 <dmg 文件>`，结果应与 SHA256SUMS 文件里的一致。
2. 双击打开 dmg，把 MaaNikki 拖到旁边的「应用程序」文件夹。已经装过旧测试版的，先完全退出 MaaNikki（包括菜单栏图标），再拖进去替换。
3. 推出 dmg。

## 第一次打开

测试版没有 Apple 开发者签名，第一次打开时系统会拦下来（提示的具体文字随 macOS 版本不同）：

1. 在「应用程序」里双击 MaaNikki，系统提示无法确认它是否安全（大意是无法验证它不含恶意软件），点「完成」（不要点「移到废纸篓」）。
2. 打开「系统设置 → 隐私与安全性」，滚到下方「安全性」一栏，会看到 MaaNikki 被阻止的提示，点「仍要打开」，输入登录密码或用触控 ID 确认。
3. 再次出现提示时点「仍要打开」。之后就可以正常双击打开了。

「仍要打开」不会去掉下载带来的隔离标记，而是把它标记为你已批准，这是正常的。如果系统提示的是「已损坏，无法打开」，说明文件有问题，请不要绕过，重新下载或联系维护者。

也可以在「终端」里运行下面这一行代替第 1–3 步（作用是去掉隔离标记）：

```sh
xattr -dr com.apple.quarantine /Applications/MaaNikki.app
```

## 授予权限

MaaNikki 需要两项权限：「屏幕录制」用于识别游戏画面，「辅助功能」用于向游戏发送按键和点击。两项都会由系统自动弹出请求，权限列表里的名字是 MaaNikki：

1. **屏幕录制**：打开 MaaNikki 后，客户端载入实例时会查找游戏窗口，这时系统会请求屏幕录制（新版系统叫「屏幕与系统录音」）。点「打开系统设置」，打开 MaaNikki 的开关。系统提示要退出并重新打开时照做——屏幕录制要在 MaaNikki 重新打开后才生效。
2. **辅助功能**：第一次连接游戏时（点连接，或者按「开始」时客户端会先连接），系统会请求辅助功能。同样点「打开系统设置」，打开 MaaNikki 的开关。辅助功能打开后马上生效，再连接一次即可，不用重新打开。

没有弹出请求、或者不小心点掉了的，也可以手动去「系统设置 → 隐私与安全性」里的「屏幕与系统录音」（旧版系统叫「屏幕录制」）和「辅助功能」打开 MaaNikki 的开关；列表里没有的话，点「+」，选择「应用程序」里的 MaaNikki。

开发者自己用源码运行的开发版，权限记在启动它的终端或远程工具名下，与这里的 MaaNikki 是两个不同的条目，互不影响。

**每次换装新的测试版之后**，系统可能会把它当成另一个应用：开关看起来还开着，实际却不起作用。遇到客户端提示没有权限、截不到画面或者按键无效时，在上面两个列表里选中 MaaNikki，点「−」删掉，再用「+」重新添加，然后重新打开 MaaNikki。也可以在「终端」里重置后重新授权：

```sh
tccutil reset ScreenCapture org.maanikki.desktop
tccutil reset Accessibility org.maanikki.desktop
```

## 第一次运行任务前

- **先看清勾选了哪些任务再按「开始」**。按「开始」会运行当前勾选的全部任务，哪怕你只是想借它触发连接和权限请求。
- **按下「开始」后切回游戏**。游戏不在最前面时任务会立即暂停（这是设计行为，避免按键发到别的应用），把游戏切回最前面就会自动继续。
- 已知现象：macOS 的「游戏模式」对游戏开启时，短促的按键会被系统拉长；是否建议为本游戏关闭游戏模式还在评估中。

## 数据放在哪里

配置、日志和调试文件都在 `~/Library/Application Support/MaaNikki`（在访达里按 Shift+Command+G 输入这个路径即可打开）。删除应用不会删除这个文件夹。反馈问题时，请在客户端「设置 → 调试」里点「导出日志」，把生成的压缩包一起发来。

## 与正式版的不同

- 不检查更新、不自动更新：新的测试版由维护者另行发出。
- 不上报诊断信息和使用统计。
- 测试版自己在后台联网的只有两项，都与正式版相同，也都不改动应用本身：
  - 游戏数据（识别用的资料和模型）：启动后和之后每 6 小时从项目在 GitHub 上的数据仓库检查一次，有新版本就下载到上面的数据文件夹。
  - 幻境预测：打开相关页面时从项目的统计服务读取一次预测，不上传任何内容。
- 客户端默认开着一个本机网页服务（端口 12701 起），只接受本机访问（127.0.0.1），用于在浏览器里操作客户端；不对局域网开放，除非在设置里打开「允许局域网访问」。
- 另外，只有你主动使用时才会联网的功能与正式版相同，例如运行「兑换码」任务时读取公开的兑换码列表、路线编辑器生成路线时读取公开的地图资料。
