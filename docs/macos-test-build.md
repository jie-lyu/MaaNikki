# MaaNikki Mac 测试版使用说明

[macOS 支持计划](macos-support-plan.md)

这是给少数测试者的 Mac 测试版，不是正式版。它的版本号与同期的 Windows 版相同，用窗口标题区分：标题里写着「Mac 测试版」和构建所用的提交号（例如「MaaNikki Mac 测试版（1a2b3c4）」），反馈问题时请一并报告这个提交号。

## 运行条件

- Apple 芯片（M 系列）的 Mac，macOS 14 或更高版本。
- App Store 版《无限暖暖》，画面设置为「全屏窗口模式」，游戏放在外接的 16:9 显示器上，运行任务期间保持在最前面。MacBook 自带屏幕、窗口模式、后台运行都不支持。
- 只开放已经在 Mac 上验证过的任务，其余任务会被跳过并提示原因。具体清单随测试版更新，以客户端里的提示为准。

## 安装

1. 下载测试包，解压后得到 `MaaNikki-v<版本>-macos-arm64-test-<提交>.dmg` 和同名的 `-SHA256SUMS.txt`。想确认文件完整，可以在「终端」里运行 `shasum -a 256 <dmg 文件>`，结果应与 SHA256SUMS 文件里的一致。
2. 双击打开 dmg，把 MaaNikki 拖到旁边的「应用程序」文件夹。已经装过旧测试版的，先完全退出 MaaNikki（包括菜单栏图标），再拖进去替换。
3. 推出 dmg。

## 第一次打开

测试版没有 Apple 开发者签名，第一次打开时系统会拦下来：

1. 在「应用程序」里双击 MaaNikki，系统提示无法验证它是否包含恶意软件，点「完成」（不要点「移到废纸篓」）。
2. 打开「系统设置 → 隐私与安全性」，滚到下方「安全性」一栏，会看到 MaaNikki 被阻止的提示，点「仍要打开」，输入登录密码或用触控 ID 确认。
3. 再次出现提示时点「仍要打开」。之后就可以正常双击打开了。

也可以在「终端」里运行下面这一行代替第 1–3 步（作用是去掉下载带来的隔离标记）：

```sh
xattr -dr com.apple.quarantine /Applications/MaaNikki.app
```

## 授予权限

MaaNikki 需要两项权限：「屏幕录制」用于识别游戏画面，「辅助功能」用于向游戏发送按键和点击。

1. 打开「系统设置 → 隐私与安全性 → 屏幕与系统录音」（旧版系统叫「屏幕录制」），打开 MaaNikki 的开关；列表里没有的话，点「+」，选择「应用程序」里的 MaaNikki。
2. 打开「系统设置 → 隐私与安全性 → 辅助功能」，同样打开 MaaNikki 的开关。
3. 完全退出 MaaNikki 再重新打开，权限才会生效。

**每次换装新的测试版之后**，系统可能会把它当成另一个应用：开关看起来还开着，实际却不起作用。遇到客户端提示没有权限、截不到画面或者按键无效时，在上面两个列表里选中 MaaNikki，点「−」删掉，再用「+」重新添加，然后重新打开 MaaNikki。也可以在「终端」里重置后重新授权：

```sh
tccutil reset ScreenCapture org.maanikki.desktop
tccutil reset Accessibility org.maanikki.desktop
```

## 数据放在哪里

配置、日志和调试文件都在 `~/Library/Application Support/MaaNikki`（在访达里按 Shift+Command+G 输入这个路径即可打开）。删除应用不会删除这个文件夹。反馈问题时，请在客户端「设置 → 调试」里点「导出日志」，把生成的压缩包一起发来。

## 与正式版的不同

- 不检查更新、不自动更新：新的测试版由维护者另行发出。
- 不上报诊断信息和使用统计。
- 游戏数据（识别用的资料和模型）仍会像正式版一样从项目的数据仓库自动下载，存放在上面的数据文件夹里，不改动应用本身。
